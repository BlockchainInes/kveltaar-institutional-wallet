# Security Policy

## Supported Version

The latest version of this repository is actively maintained.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please do not disclose it publicly before responsible disclosure.

Please open a private security report through GitHub Security Advisories or contact the maintainer directly.

Every report will be reviewed and acknowledged as quickly as possible.

## Scope

This repository contains Solidity smart contracts for educational and portfolio purposes.

Although the contracts are automatically tested and analyzed using Foundry and Slither, they have **not** been independently audited.

Do not use these contracts in production without an independent professional security audit.
